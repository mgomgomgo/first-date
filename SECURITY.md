# Security and privacy

First Date is a set of instructions and templates, not a hosted service. This repository does not run a telemetry or profile-collection backend.

**Never commit actual personal profiles, private transcripts, credentials, or another person's sensitive details to this public repository.** The example templates contain only placeholders. Do not paste private data into public GitHub Issues or pull requests.

Users choose whether context is retained, in what scope, and via which AI tool. Installing the skill does not guarantee that an AI provider stores, deletes, exports or synchronizes memory in any particular way; consult the provider's controls.

If you discover a privacy or security problem, avoid sharing personal data in a public issue. Contact the repository maintainer privately via GitHub where available. Until a private reporting channel is configured, report only nonsensitive reproduction details publicly.

Human oversight and the host's own security policies continue to apply.
