# Contributing to First Date

Thanks for helping make human-AI collaboration more contextual, portable, and user-controlled.

## What we're looking for

- Improvements to conversational flow and clarity.
- Real-world examples with fabricated or explicitly authorized context.
- Platform-specific installation and persistence adapters.
- Accessibility, localization, and privacy reviews.
- Tests showing when the protocol should *not* interrupt a task.

## Ground rules

1. Do **not** submit real private context profiles, chat transcripts, credentials, or identifying user data.
2. Preserve user consent, data minimization, explicit scope boundaries, and portability.
3. Do not claim a platform feature works unless you have verified it.
4. Prefer small, focused pull requests with a clear example of the behavior being improved.
5. Report security or privacy vulnerabilities privately to the maintainer rather than posting sensitive details in an issue.

## Pull requests

Explain the problem, the proposed change, how it was tested, and whether it affects user consent, profile storage, or global-to-project inheritance.

## Code of conduct

Be respectful, constructive, and assume good intent. Disagreement about a design choice is welcome; personal attacks are not.
